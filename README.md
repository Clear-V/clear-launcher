# Clear Launcher

A privacy-focused Android launcher for people with intellectual and developmental disabilities (IDD).

Built by [Clear Voice LLC](https://clearvoiceworks.org) — free, open source, and built with care.

---

## What is Clear Launcher?

Clear Launcher replaces your Android home screen with a simple, focused experience. Caregivers choose exactly which apps appear — nothing else is accessible without a PIN.

Designed for:
- People with intellectual and developmental disabilities
- Caregivers, parents, and support workers
- Schools, group homes, and care organizations

---

## Features

- **Simple app grid** — only the apps you choose, nothing else
- **Caregiver PIN** — 6-digit PIN with progressive lockout and recovery code
- **PIN scramble** — randomizes keypad to prevent shoulder surfing
- **Adaptive theming** — colors derived from wallpaper for a warm, personal feel
- **Grid customization** — 2, 3, or 4 column layouts
- **Icon and text sizing** — accessible for all visual needs
- **Dark and light modes** — with full wallpaper color extraction
- **No accounts** — everything stays on device
- **No tracking** — no analytics, no ads, no cloud
- **Free forever** — GPL v3 licensed

## Building from Source

```bash
git clone https://github.com/Clear-V/clear-launcher.git
cd clear-launcher
./gradlew assembleDebug
```

Requires Android Studio or the Android SDK with API 34+.
